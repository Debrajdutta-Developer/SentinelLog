# Security Policy

## Scope

SentinelLog is a defensive authentication-monitoring and detection-engineering project. It is intended for systems, logs, and environments where the operator has explicit authorization.

## Reporting a security issue

Please do not publish sensitive vulnerability details in a public issue. Report security concerns privately through the repository owner's available GitHub contact channels.

Include:
- affected component or file
- reproducible steps
- expected behavior
- observed behavior
- security impact
- a minimal safe proof of concept, if needed

Do not include real credentials, personal data, production secrets, or unauthorized system data.

## Safe-use boundary

SentinelLog must not be used to obtain unauthorized access, conduct credential attacks, or monitor systems without permission. Detection output is an investigation signal and is not, by itself, proof of compromise.
